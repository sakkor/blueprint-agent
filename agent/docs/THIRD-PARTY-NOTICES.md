# Third-party components

Blueprint Agent source is independently written for this assignment. The executable bundles Python 3.12 and Tcl/Tk, and uses PyYAML 6.0.3. It is packaged with PyInstaller 6.16.0 and its bootloader. Available distribution license texts are included under licenses/. PyInstaller has a bootloader exception; consult its included license text.

Reference projects are credited in RESEARCH.md. No Claw Code source or educational reference prose is incorporated into the application source. The supplied architecture examples are the user's professor-provided inputs, preserved with their original content.
